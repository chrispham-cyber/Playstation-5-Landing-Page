# PlayStation 5 Landing Page

A responsive PlayStation 5 marketing landing page built with **HTML5, CSS, Bootstrap 4, and vanilla JavaScript**. Coursework project (Web Applications, Ho Chi Minh City Open University), later refactored for accessibility.

## Live

- [Login page](https://chrispham-cyber.github.io/Playstation-5-Landing-Page/)
- [Home page](https://chrispham-cyber.github.io/Playstation-5-Landing-Page/home.html)

**Demo login (client-side only — not real authentication):** `admin@gmail.com` / `123`

> The sign-in is a front-end demo: credentials are checked in JavaScript purely to show the flow. It is not secure and stores nothing. Real authentication would validate on a server against hashed passwords.

## Accessibility

Refactored to meet WCAG 2.1 AA basics: descriptive `alt` text on all images, accessible names on icon-only links and buttons, a `title` on the map iframe, a single `<h1>` with a logical heading order, a "skip to content" link, visible keyboard focus, and improved color contrast. Audited with Lighthouse and axe.
